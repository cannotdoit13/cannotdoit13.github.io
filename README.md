# Personal site

Plain static page — no framework, no animation stack.

## Local preview

Open `index.html` in a browser, or:

```bash
npx --yes serve .
```

## GitHub Pages

1. Create a repo on your account (e.g. `cannotdoit13.github.io` for a user site, or any repo name).
2. Push this folder to `main`.
3. Repo **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. After the workflow runs, the site is live.

Add your resume as `resume.pdf` in this folder (same name as the link in `index.html`).

## Edit content

All copy is in `index.html`. Styles in `styles.css`.
